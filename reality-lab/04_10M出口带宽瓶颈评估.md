# 04. 出口 A 10 Mbps 限速瓶颈评估与双栈负载均衡方案

**状态**：结论明确，附带宽算术评估与分流优化方案
**说明**：用户裁定暂不做本地实测，本文件基于算术推导、日常应用吞吐模型与成本/收益对比给出评估。

---

## 1. 带宽算术与应用吞吐需求评估

### 1.1 10 Mbps 的实际物理极限
- **理论峰值下载速率**：$10 \text{ Mbps} \div 8 = 1.25 \text{ MB/s}$。
- **协议开销（TCP/IP + TLS + SOCKS5 封装）**：实际有效载荷速率约为 **1.0 ~ 1.1 MB/s**。

### 1.2 典型场景体验评估

| 应用场景 | 带宽需求峰值 | 10 Mbps 出口 A 表现 | 体验评价 |
|---|---|---|---|
| **AI Agent API 对话** (OpenAI / Claude / Gemini) | 0.2 ~ 0.5 Mbps (文本 Token 流) | **完全无压力** | 🟢 **优秀** (首包延迟取决于 RTT，非带宽) |
| **网页浏览 / GitHub 代码提交** | 1 ~ 3 Mbps (短时突发) | **流畅** (加载稍延迟 0.5s) | 🟢 **良好** |
| **高清视频** (YouTube / Bilibili 1080p60) | 5 ~ 8 Mbps | **勉强维持** | 🟡 **临界** (4K 必卡顿) |
| **大模型权重 / 软件更新 / Git Clone 大仓库** | 50 ~ 100+ Mbps | **极大瓶颈** (1GB 文件需 15 分钟) | 🔴 **不可接受** |

**结论 1**：对于 **AI 开发、Agent 协作、远程 SSH、网页浏览**，10 Mbps 静态住宅 IPv4 **完全不是瓶颈**；但若有**大文件下载或高码率视频**需求，10 Mbps 是绝对硬瓶颈。

---

## 2. 三种架构调整路径的成本收益对比

| 方案 | 架构描述 | 优势 | 劣势/成本 | 推荐度 |
|---|---|---|---|---|
| **路径 1：升级出口 A 带宽** | 续费购买 Rola 50M/100M 静态住宅 IPv4 | 简单直接，IPv4 速率提升 | 成本翻倍（住宅 IP 带宽极贵） | 🟡 仅当大文件需求频繁时考虑 |
| **路径 2：分流双栈负载 (A+B)** | **大流量走出口 B (不限速 IPv6) / 敏感流量走 A** | **零增加成本**，极大提升吞吐 | 需在 Hub 配置域名/协议分流 | 🟢 **强烈推荐** |
| **路径 3：非敏感流量直连 Hub 出口** | Google/Cloudflare/开源镜像直走 GCP IPv4 | 享受 GCP 1Gbps+ 直连带宽 | 损失住宅 IP 属性 (可能触发 Cloudflare Captcha) | 🟢 **强烈推荐 (按域名分流)** |

## 3. 落地建议：sing-box 出口分流规则补丁 (分流方案 2+3)

无需增加任何费用，在 GCP Hub VM 的 `sing-box` 配置中加入域名分流，使高带宽需求流量直接由 Hub 出口或走出口 B (IPv6)：

```json
{
  "route": {
    "rules": [
      {
        "domain_suffix": [
          "githubusercontent.com",
          "huggingface.co",
          "googlevideo.com",
          "youtube.com",
          "cdn.site.com"
        ],
        "outbound": "direct-out"
      },
      {
        "ip_version": 6,
        "outbound": "socks-out-b"
      },
      {
        "outbound": "socks-out-a"
      }
    ]
  }
}
```

### 效果预估：
1. **AI API (OpenAI/Anthropic/Gemini) & 风控敏感域名**：继续走出口 A (Rola 住宅 IPv4)，确保账号安全，10M 带宽绰绰有余。
2. **YouTube / 大文件 / Docker 镜像 / GitHub Code**：分流走 Hub 直连 (`direct-out`) 或出口 B (IPv6)，吞吐从 10 Mbps 提升至 **100M ~ 1Gbps**。
